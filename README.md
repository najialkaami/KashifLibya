# كاشف ليبيا
1. افتح المجلد في Android Studio (Koala أو أحدث) ودعه يزامن Gradle (سيُنشئ الـ wrapper).
2. شغّله على هاتف حقيقي بأندرويد 10 أو أحدث (الكشف لا يعمل على المحاكي بشكل موثوق).
3. من التطبيق: اضغط «تفعيل» واختر «كاشف ليبيا» كتطبيق فحص المكالمات، ثم اسمح بالإشعارات.
4. اطلب من رقم آخر أن يتصل بك: ستظهر إشعارات باسم المتصل، والأرقام المحظورة تُرفض تلقائياً.
